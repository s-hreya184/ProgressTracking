🌐 How to Share Online with Your Team

You can host this leaderboard online for free so every mentor on your team can bookmark it on their phone or laptop.

Option 1: GitHub Pages (100% Free & Automatic) Recommended

The repo already includes a GitHub Actions cron job that scrapes profiles every 4 hours and automatically updates the site.

  1. Push this folder to a GitHub repository.
  2. Go to Settings > Pages > Build and deployment.
  3. Choose GitHub Actions.
  4. Your team gets a live link: https://your-org.github.io/repo/!
Option 2: Live Sync from Google Sheets

If you update mentors or student links in your Google Sheet, publish the sheet as CSV (File > Share > Publish to web > CSV) and set the URL in the scraper or GitHub Secrets. It will sync automatically!

Run manual update locally: 
python scraper.py
